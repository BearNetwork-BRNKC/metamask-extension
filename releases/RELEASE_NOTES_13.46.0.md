### 安裝方式
1. 下載下方 bnes-metamask-extension-v13.46.0.zip
2. 解壓縮後，開啟 Chrome（或 Brave）
3. 進入 chrome://extensions/
4. 開啟右上角「開發人員模式」
5. 點擊「載入已解壓縮的擴充功能」
6. 選擇解壓縮後的資料夾

> **注意**：此版本不上架 Chrome Web Store，僅提供開源下載安裝。
